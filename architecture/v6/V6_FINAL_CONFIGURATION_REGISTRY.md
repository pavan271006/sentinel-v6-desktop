## 1. Global Platform Configuration (`SentinelConfig`)

Managed via TOML configuration (`~/.sentinel/config.toml` or per-project configuration).

```toml
[proxy]
bind_address = "127.0.0.1"
port = 8080
upstream_proxy = ""
tls_cert_path = "~/.sentinel/ca.pem"

[scope]
default_action = "DENY"
max_rule_length = 1000
rule_evaluation_timeout_ms = 100

[storage]
sqlite_path = "project.db"
tantivy_path = "indices/"
blob_store_path = "blobs/"

[scanner]
default_concurrency = 10
max_concurrency = 100
request_timeout_ms = 5000

[ai]
enabled = false
provider = "local"
model = "deepseek-coder:6.7b"
policy_enforcement = true

[plugins]
plugin_directory = "plugins/"
max_wasm_memory_mb = 128
allow_rhai_scripts = true
```

## 2. Configuration Subsystems & Typed Schemas

| Config Struct | Subsystem Owner | Mandatory Keys & Types | Default Value | Validation Rules |
|---|---|---|---|---|
| **`ProxyConfig`** | `ProxyEngine` (SUB-01) | `bind_address` (string), `port` (u16), `upstream_proxy` (Option<string>), `tls_cert_path` (string) | `127.0.0.1:8080` | Port must be valid 1-65535; CA certificate must exist or be auto-generated. |
| **`ScopeConfig`** | `ScopeEngine` (SUB-04) | `default_action` (string), `max_rule_length` (usize), `rule_evaluation_timeout_ms` (u64) | `DENY`, `1000`, `100` | `default_action` must enforce DENY; evaluation timeout bounds prevent ReDoS. |
| **`StorageConfig`** | `ObservationStore` (SUB-03) | `sqlite_path` (string), `tantivy_path` (string), `blob_store_path` (string) | `project.db`, `indices/`, `blobs/` | Paths must be writable; SQLite WAL mode enforced. |
| **`ScannerConfig`** | `ScanOrchestrator` (SUB-07) | `default_concurrency` (u32), `max_concurrency` (u32), `request_timeout_ms` (u64) | `10`, `100`, `5000` | Max concurrency bounded at 100 to prevent local network exhaustion. |
| **`AiConfig`** | `AiEngine` (SUB-18) | `enabled` (bool), `provider` (string), `model` (string), `policy_enforcement` (bool) | `false`, `local`, `deepseek-coder:6.7b`, `true` | AI is optional; policy_enforcement must be true whenever enabled. |
| **`PluginConfig`** | `PluginRuntime` (SUB-20) | `plugin_directory` (string), `max_wasm_memory_mb` (u32), `allow_rhai_scripts` (bool) | `plugins/`, `128`, `true` | Maximum WASM memory allocation clamped at 128MB. |

## 3. Runtime & Execution Budgets (`ResourceBudget`)

- `max_requests`: Hard cap on HTTP requests generated by a single test task (default: `10,000`).
- `max_duration_secs`: Maximum run time for a scan phase before automatic checkpoint and pause (default: `3,600` seconds).
