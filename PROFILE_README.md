## 🚀 Flagship Project: Sentinel V6 Desktop

I am the creator and lead maintainer of **[Sentinel V6 Desktop](https://github.com/pavan271006/sentinel-v6-desktop)**, an open-source web application security assessment suite and intercepting proxy designed to replace heavyweight legacy Java proxies.

- ⚡ **Lightweight Alternative to Burp Suite**: Operates within a sub-100MB memory footprint with zero JVM overhead and instant (<500ms) cold start times.
- 🚀 **Unthrottled Intruder / Parameter Fuzzer**: Native Tokio concurrency engine delivering 10,000+ to 30,000+ requests per second without artificial paywalls.
- 🎯 **Autonomous Multi-Oracle SQL Injection Scanner**: Differential Boolean diffing, error-based pattern matching, UNION extraction, and SPRT statistical timing.
- 📡 **Native Out-of-Band (OAST) Security Testing**: Built-in Burp Collaborator parity powered by Interactsh for blind vulnerability verification.
- 🌐 **Modern React + Tauri Desktop UI**: Micro-batched 30 FPS event streaming that remains completely fluid during high-volume scans.
