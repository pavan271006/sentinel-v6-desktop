## 1. Strict Finding Lifecycle State Machine (SEC-06)

The canonical architecture enforces a formal, unidirectional state machine for all vulnerability findings:

```
[ Candidate ] ──► [ Verified ] ──► [ Confirmed ] ──┬──► [ Reported ] ──► [ Remediated ] ──► [ Regression ]
      │                 │                          └──► [ Remediated ]
      └──► [ FalsePos ] └──► [ FalsePos ]
```

### Transition Enforcement Verification:
- **Allowed Transitions**:
  - `Candidate` -> `Verified` (via `VerificationEngine`)
  - `Candidate` -> `FalsePositive`
  - `Verified` -> `Confirmed` (via Pentester / Policy)
  - `Confirmed` -> `Reported` / `Remediated`
  - `Remediated` -> `Regression` (upon retest failure)
- **Illegal Transitions (Strictly Rejected)**:
  - `Candidate` -> `Confirmed` (FAILS with `SentinelError::InvariantViolation`)
  - `Candidate` -> `Remediated` (FAILS)
  - `FalsePositive` -> `Confirmed` (FAILS)

## 2. 4 Deterministic Verification Strategies

Every verified candidate must have an associated `VerificationResult` generated by at least one of the 4 verification strategies:

| Strategy | Trigger Condition | Proof Generated | Confidence Score |
|:---|:---|:---|:---:|
| **1. Content** | Vulnerability marker or error syntax in response body | CAS blob with byte offset of reflected payload | `1.0` |
| **2. ResponseDiff** | Statistically significant differential vs baseline response | Line-by-line unified diff and status code change | `0.85 - 0.99` |
| **3. Timing** | Statistically verified delay exceeding threshold ($t_{probe} - t_{base} \ge 5000\text{ms}$) | Nanosecond timing duration histogram | `0.90` |
| **4. OAST** | Out-of-band DNS/HTTP callback matching candidate token | DNS query record or HTTP interaction log in CAS | `1.0` |

## 3. Cryptographic Evidence Linkage (SEC-07)

- **Immutable Hash Chains**: Every `Evidence` record references a CAS SHA-256 blob containing the raw request/response bytes or screenshot.
- **Relational Integrity**: Deleting or tampering with evidence triggers SQLite foreign key failures or CAS hash mismatch errors (`Blob SHA-256 hash mismatch (SEC-07)`).
- **Audit Trails**: Finding creation, triage, and state transitions are recorded into `audit_events` with timestamps and operator identity.
