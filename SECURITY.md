# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 6.0.x   | :white_check_mark: |
| < 6.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within Sentinel V6 Desktop, please report it privately to **Pavan (@pavan271006)** by opening a Private Vulnerability Report on GitHub or emailing the maintainer.
