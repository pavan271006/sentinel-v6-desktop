=== SECURITY INVARIANTS ===
[SEC-01] Scope Authorization Invariant
  Statement: No active outbound network packet may be transmitted without an explicit ScopeDecision::Allowed from ScopeEngine. Default is DENY (fail-closed).
  Enforcement: ProxyEngine (SUB-01), ScanOrchestrator (SUB-07), BrowserService (SUB-15), Adapters (SUB-22..25)
  Verification: Unit test asserting network connection attempt to out-of-scope URI immediately returns ScopeViolation error without TCP handshake.
[SEC-02] OAST Token Confidentiality Invariant
  Statement: Out-of-band interaction tokens must use AES-256-GCM authenticated encryption. No plaintext target identifier may exist in the token string.
  Enforcement: OASTServer (SUB-16)
  Verification: Token generation test confirming ciphertext entropy and absence of target hostname in raw token string.
[SEC-03] Host AI Policy Gate Invariant
  Statement: AI may never execute network requests autonomously. All AI-generated strings must pass the 5-layer AIPolicyEngine and ScopeEngine.
  Enforcement: AIPolicyEngine (SUB-19), AIEngine (SUB-18)
  Verification: Policy test confirming destructive prompt string is intercepted and rejected with PolicyResult::Blocked.
[SEC-04] WASM Capability Drop Invariant
  Statement: WASM plugins execute in Wasmtime with default-deny capabilities (network=false, filesystem=false, secrets=false).
  Enforcement: PluginRuntime (SUB-20)
  Verification: Sandbox test verifying unpermitted WASM socket open attempt traps with SentinelError::SandboxViolation.
[SEC-05] Research Module Optionality Invariant
  Statement: Research engines (SMT, RL, Crypto) are feature-flagged behind sentinel-research. Core platform compiles and passes 100% of tests with default-features = false.
  Enforcement: Cargo crate feature architecture (SUB-26, SUB-27, SUB-28)
  Verification: Cargo build and test command running --no-default-features succeeding cleanly.
[SEC-06] Finding Proof Requirement Invariant
  Statement: No Candidate may transition to FindingLifecycle::Verified without empirical, differential, or cryptographic Evidence from VerificationEngine.
  Enforcement: VerificationEngine (SUB-09), Finding state machine
  Verification: State machine test verifying transition from Candidate to Verified fails if Evidence vector is empty.
[SEC-07] Evidence Immutability Invariant
  Statement: Evidence blobs stored in blob storage are content-addressed (SHA-256). Any modification invalidates hash integrity.
  Enforcement: ObservationStore (SUB-03), Blob Store
  Verification: Tamper test asserting modified blob content triggers SHA-256 mismatch error on retrieval.
[SEC-08] Cross-Tenant Project Isolation Invariant
  Statement: SQLite databases and blob directories are physically partitioned per project. Multi-tenant project data cannot intermingle.
  Enforcement: ObservationStore (SUB-03), Filesystem layout
  Verification: Project switch test verifying queries in Project A return zero records from Project B.
[SEC-09] Zero Plaintext Secrets Invariant
  Statement: Credentials, API keys, and session tokens must use SecretReference UUID pointing to OS Keychain. No plaintext in DB, logs, or events.
  Enforcement: IdentityManager (SUB-12), SQLite schema, Tracing logger
  Verification: Database audit test scanning credentials table and log outputs asserting zero regex matches for plaintext credentials.
[SEC-10] Triple Representation Invariant
  Statement: Every transaction retains byte-exact raw blob, parsed structured representation, and normalized text for search.
  Enforcement: HTTPParser (SUB-02), ProxyEngine (SUB-01), ObservationStore (SUB-03)
  Verification: Round-trip parser test asserting raw byte slice is identical before and after parsing and storage.
[SEC-11] WebView Sandbox Isolation Invariant
  Statement: Tauri UI WebView never renders untrusted target HTML directly. Scanning browser is isolated out-of-process in BrowserDaemon.
  Enforcement: BrowserService (SUB-15), Tauri IPC layer
  Verification: DOM injection test verifying malicious payload executes in isolated Playwright context without executing in Tauri WebView.
[SEC-12] Bounded Buffer Backpressure Invariant
  Statement: All EventBus channels enforce bounded capacities with drop-on-lag for telemetry and backpressure for critical events.
  Enforcement: EventBus (SUB-05)
  Verification: Channel saturation test verifying broadcast channel drops excess messages while critical channel applies backpressure.
