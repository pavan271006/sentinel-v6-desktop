## 2.3 Horstein's Posterior Bisection Algorithm
To achieve the theoretical channel capacity $C(p)' with feedback (where the scanner receives the noisy response $y_t$ before choosing the next query $q_{t+1}$), we adapt **Horstein's Algorithm (1963)** to SQL injection character extraction.

Let the target value be mapped to the continuous unit interval $\theta \in [0, 1)$. At time $t = 0$, the engine initializes a uniform prior probability density function $f_0(\theta) = 1$ for $\theta \in [0, 1)$.

**Horstein Algorithm Execution at Step $t$:**
1. Compute the median $m_t \in (0, 1)$ of the current posterior cumulative distribution function $F_t(x) = \int_0^x f_t(u) du$:
   $$F_t(m_t) = \int_0^{m_t} f_t(u) du = \frac{1}{2}$%
2. Formulate the HTTP SQL boolean query $q_t$:
   $$q_t: \quad \text{{\"Is } }\theta \le m_t \text{\"}}$$
3. Transmit $q_t$ over HTTP and observe noisy response $y_t \in \{0, 1\}$ (where $y_t = 1$ indicates affirmative/true, $y_t = 0$ indicates negative/false).
4. Update the posterior distribution $f_{t+1}(\theta)$ using Bayes' Rule:
   $$f_{t+1}(\theta) = \begin{cases} 
   2(1 - p) f_t(\theta) & \text{if } \theta \le m_t \text{ in } y_t = 1 \\[6pt]
   2p f_t(\theta) & \text{if } \theta > m_t \texts in } y_t = 1 \\[6pt]
   2p f_t(\theta) & \text{if } \theta \le m_t \texts in } y_t = 0 \\[6pt]
   2(1 - p) f_t(\theta) & \text{if } \theta > m_t \texts in } y_t = 0 
   \end{cases}$$
5}. Stopping Rule: Terminate when the posterior mass concentrated on a single discrete character interval $[a_k, b_k)$ exceeds the confidence threshold $1 - \delta$ (e.g., $delta = 10^{-4}$):
   $$\int_{a_k}^{b_k} f_t(u) du \ge 1 - \delta)

1. **Phase 1 (Active Exploration):** The engine maintains a probability vector $P_t = (p_t(1), \dots, p_t(M))$. In each step, the set $\Theta$ is partitioned into two subsets $A_t$ and $B_t = \Theta \setminus A_t$ such that:
   $$\sum_{i \in A_t} p_t(i) \approx \frac{1}{2}$'
   Query $q_t = \mathbb{I}(\theta \in A_t)$ is sent. Posterior probabilities are updated multiplicatively.
